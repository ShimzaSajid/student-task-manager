# student-task-manager

A simple Python console application for managing student tasks.

## Features
- Add tasks (empty titles are rejected)
- View all tasks
- Mark tasks as completed
- Delete tasks by ID
- Automated tests with GitHub Actions

## Setup
1. Install Python 3.11 or newer.
2. Clone the repository:

       git clone https://github.com/ShimzaSajid/student-task-manager.git
       cd student-task-manager

## Usage
Run the application with:

    python main.py

See the [User Guide](docs/user-guide.md) for details on each menu option.

## Running Tests

    python -m unittest discover -s tests -v
